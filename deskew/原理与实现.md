## 1. 问题：畸变从哪来，有多大

### 1.1 机理

这台雷达不是"拍照"，是**逐点顺序扫描**（README 5.3 节逆向的协议结论）：

- 设备 A：每点 5 µs，每包 96 点 = 480 µs，点频 200 kHz；
- 一段 0.1 s 的"帧"里，先打的点和后打的点相差整整 0.1 s；
- 载体（船）在这 0.1 s 里在转、在晃。

对世界系里静止的目标点 P，t_k 时刻测到的是

```
p_k = R(t_k)ᵀ · (P − t(t_k))
```

R(t_k)、t(t_k) 是 t_k 那一刻传感器相对世界的姿态和位置——**每个点用的是不同的坐标系**。
把整段点直接叠加 = 把 N 个坐标系强行合并：直的墙变弧线、点云沿运动方向拖影，
和相机的果冻效应（rolling shutter distortion）同一性质，这里叫**运动畸变**。

### 1.2 本数据的量级（为什么值得做）

| 数据 | 载体运动 | 每窗旋转（0.1 s） | 点位移实测 |
|---|---|---|---|
| `6666` 20–35 s（运动段） | \|ω\| 均值 **0.108 rad/s ≈ 6.2°/s**，峰值 0.137 | 均值 0.617°，最大 0.753° | 均值 9.32 cm，p95 24.25 cm，**最大 90.64 cm** |
| `99999`（基本静止） | \|ω\| 均值 0.018 rad/s | 均值 0.102° | 均值 1.17 cm，最大 17.80 cm |

几何直觉：位移 ≈ 旋转角 × 距离。本数据平均距离 17.8 m（0.62°/2 × 17.8 ≈ 9.6 cm），
最远 98.6 m；实测最大位移 90.64 cm 正好出现在 **84.5 m 远的点**上（θ/2 × 84.5 ≈ 0.9 m）✓。

也就是说：**运动段里 0.1 s 一"帧"的点云自带分米级拖影，远处的目标拖近 1 米**——不去掉它，
后续做配准/聚类/跟踪都会被污染。

## 2. 原料盘点：有什么、缺什么（这决定了方案）

| 有的 | 怎么来的 | 用处 |
|---|---|---|
| 陀螺 200 Hz（rad/s） | `IMU\*_imu.csv`，export_imu.py ③ | **旋转预积分的全部输入** |
| 加速度 200 Hz（m/s²） | 同上 | `--trans` 平移项 |
| 逐点 timestamp（µs 级） | `LIDAR\*_radar.csv`，export_radar.py ②（点内偏移 5 µs 已算好） | 逐点查表的时间键 |
| **同一时钟** | 两流来自同一台设备 192.168.1.100（端口 56300 点云 / 56400 IMU）、同一个 pcap 的抓包时间 | **时间零偏移，免标定** |

| 缺的 | 后果 | 对策 |
|---|---|---|
| 磁力计 | 无 yaw | 无所谓——旋转预积分只要陀螺（相对旋转与 yaw 无关） |
| 速度/位置观测（GNSS 等） | 平移补偿的初速度未知 | `--trans` 取 v₀=0 + 窗内均值当重力：只补振荡平移（§4.4） |
| IMU-雷达外参标定 | 轴对应关系未知 | 假设同壳体、外参=单位阵（§8.1） |

结论：做**以旋转为主的、传感器系内的运动补偿**——这也是 LIO-SAM / FAST-LIO 这类系统
里点云去畸变的第一步（它们后续再靠状态估计精修）。

## 4. 数学原理

### 4.0 记号

- `R(t)`：t 时刻传感器（体）系 B(t) 相对惯性系的旋转；
- 陀螺测的 ω(t) 是**体系下**的角速度，所以传播是右乘：
  `R(t_{i+1}) = R(t_i) · Exp(ω·Δt)`；
- `Q(t) := R(t_lo)ᵀ·R(t)`：相对窗起始 t_lo 的旋转（代码里 `quats` 数组）；
- `ΔR(t_ref→t_k) := R(t_ref)ᵀ·R(t_k) = Q(t_ref)⁻¹·Q(t_k)`。

### 4.1 补偿公式怎么来的

把"打点时刻的坐标"搬回"参考时刻的坐标"，推导只有三行。
定义参考系下的目标位置 `p_ref := R(t_ref)ᵀ(P − t(t_ref))`，代入 §1.1 的量测模型：

```
p_ref = R(t_ref)ᵀ·R(t_k)·p_k + R(t_ref)ᵀ·[t(t_k) − t(t_ref)]
      = ΔR·p_k + Δp_rel
```

- 第一项就是**旋转补偿**（默认行为）；
- 第二项是**平移补偿**（`--trans`）。

### 4.2 旋转预积分的递推（`integrate_window`，imu.py:224）

**节点**：`times = [t_lo] + (t_lo, t_hi] 内的真实 IMU 样本 + [t_hi]`。
两个端点一般不落在 IMU 样本上，ω 用相邻样本**线性插值**补（`ImuData.omega_at:206`）。

**递推**（梯形：ω 取两端平均）：

```
q₀ = (1, 0, 0, 0)
q_{i+1} = normalize( qᵢ ⊗ exp_q( ω_mid·Δtᵢ ) )
   ω_mid = (ωᵢ + ω_{i+1})/2 ， Δtᵢ = times[i+1] − times[i]
```

`exp_q`（`q_exp:94`）是旋转向量 → 四元数的指数映射：θ = |ω·Δt|，
q = (cos θ/2, ω̂·sin θ/2)。`⊗` 是 Hamilton 四元数乘法（`q_mul:74`）。

为什么这么积是对的（误差量级都算过）：

- 常值 ω：离散乘积 ∏exp(ωΔt) **精确**等于 exp(ω·ΣΔt)——自检里 1.33e-10 的残差只是浮点；
- 线性变化的 ω：梯形（中点）法局部误差 O(Δt³)，Δt=5 ms → ~1e-9 rad；
- 每步做 `q_norm` 归一化，浮点漂移不累积。

### 4.3 为什么叫"预"积分

Forster 预积分的核心：**积出来的 ΔR 只依赖 [t_lo, t] 的 IMU 测量和偏置**，
不依赖任何全局状态（初始姿态、位置、速度）。好处：

1. 全局位姿改了不用重积分（优化器迭代时省算力）；
2. 每个窗从单位四元数重新起步，天然满足——`imu.py` 里每个窗独立调
   `integrate_window`，窗与窗之间零耦合、零漂移传播；
3. 偏置可以作为独立变量修正（本实现没做偏置修正，见 §8.3，留了 `--gyro-bias` 手工扣除）。

出处：Forster et al., *IMU Preintegration on Manifold for Efficient Visual-Inertial
Maximum-a-Posteriori Estimation*, RSS 2016 / TRO 2017。本实现是其"无偏置修正"的简化版。

### 4.4 平移项（`--trans`）

Δp_rel 不能直接积分，要换到窗起始系。令 `D(t) := R(t_lo)ᵀ·[t(t) − t(t_lo)]`，则：

```
Δp_rel = R(t_ref)ᵀ·R(t_lo)·[D(t_k) − D(t_ref)] = Q(t_ref)⁻¹·[D(t_k) − D(t_ref)]
```

D 的构造（`integrate_window` 平移分支，imu.py:258 起）：

```
a_lo(τ) = Q(τ)·a(τ) − g_lo        ← 加速度转到窗起始系，扣重力
D(t)   = ∫∫ a_lo dτ²  （速度初值 v(t_lo) = 0）
```

两个关键取舍，都有明确后果：

- **g_lo 取窗内 mean(Q·a)**：假设"窗内真实加速度均值≈0"。船的波浪振荡满足
  （正负抵消）；**持续加速会被吸进重力估计里补不掉**——这是没有速度观测时的本质限制，
  不是实现缺陷。
- **v(t_lo)=0**：匀速段的 D 恒为 0 → 平移项"不添乱也不帮忙"。它补的只是
  **加速度攒出来的位移**（振荡项）。

数值积分：`v_{i+1} = v_i + a_mid·Δt`；`D_{i+1} = D_i + v_i·Δt + ½·a_mid·Δt²`。

在本数据上的实测贡献（§6.5）：**0.18 mm**——物理上 0.1 s 窗内
a≈0.5 m/s² 只能攒出 ~2.5 mm 位移上限，旋转项（9.3 cm）才是主角。

### 4.5 逐点查表与插值（`_state_at`，imu.py:293）

点频 200 kHz，IMU 只有 200 Hz——**一个 IMU 间隔里塞着约 1000 个点**，
所以先把 IMU 积成节点链（§4.2，一个窗只有 ~20 个节点），点来了再查表：

```
t_k ∈ [times[i], times[i+1])  →  α = (t_k − tᵢ)/Δtᵢ
q(t_k)  = nlerp(qᵢ, q_{i+1}, α)     ← 带点积符号校正 + 归一化（q_nlerp:126）
D(t_k)  = 线性插值
```

nlerp vs slerp 的误差是 O(θ⁴)，每间隔 θ≈ω·Δt≈1.25 mrad → ~1e-12 rad，忽略。
点时间单调，游标只前进，**每点 O(1)**，没有二分、没有重扫。

### 4.6 参考时刻的三种取法

`--ref start | mid | end` 只改 t_ref 代入的位置，窗内积分不变。
实现上整窗先缓冲（`_Win:313`，0.1 s ≈ 1–2 万行，MB 级），积分完统一变换，
所以 mid/end 不需要二次积分。选 mid 可让最大 |Δt| 减半（旋转角减半，
但补偿语义变成"以窗中点为基准"）。默认 start，和"帧起始对齐"的直觉一致。

## 6. 验证体系：怎么知道它是对的

四层证据，从"数学正确"到"真实数据上合理"。

### 6.1 数学分：预积分 vs 解析解（`--selftest` 第一层，`_math_check:569`）

合成常值 ω=(0,0,0.25) rad/s、200 Hz、2 s，逐节点比解析解 R_z(0.25t)：

```
旋转预积分 vs 解析解   最大误差 1.33e-10（浮点精度级）
平移预积分 vs 解析解   最大误差 2.9e-5 m = 200 Hz 梯形离散误差的理论量级（0.03 mm）
```

这一层证明**递推、指数映射、插值的数学全对**，不受 CSV 落盘精度干扰。

### 6.2 端到端合成：已知运动 → 合成 CSV → 全流程 → 比真值（`selftest:622`）

造"平台按已知规律运动 + 场景点静止"的 IMU/雷达 CSV，喂给 `convert`，读回比真值：

| 用例 | 期望 | 结果 |
|---|---|---|
| 纯旋转 ωz=0.25，ref=start | 回到 p_w | 误差 1.00e-4 m（= %.4f 量化）✓ |
| 纯旋转 ωz=0.25，ref=mid | 回到 R_z(θ_mid)ᵀp_w | 1.09e-4 m ✓ |
| 振荡平移 a=2sin(πt)，--trans | 回到 p_w | 1.00e-4 m ✓ |
| 静止 | 应零位移 | **0.00** ✓ |

采样点故意取 3.7 ms（不对齐 5 ms 的 IMU 网格），逼出插值路径。容差 3e-4
是输出 `%.4f` 的量化水平——算法本身误差在 6.1 已证到 1e-10。

### 6.3 静止对照：真实数据的两种独立口径互证

`99999`（近乎静止）：每窗旋转均值 **0.1015°**，
而陀螺原始均值直接乘窗长得 **0.0181 rad/s × 0.1 s = 0.1038°**——两条完全独立的
计算路径（积分 vs 均值×窗长）差 2% ✓。说明积分器没凭空造运动。

### 6.4 物理自洽：位移 = 角 × 距离

旋转-only 补偿里逐点位移 |Δp| = |Δθ|·r（r = 点到传感器的距离）。6666 运动段：

```
实测（按点加权）：9.32 cm
理论：(θ̄/2) × r̄ = (0.6166°/2) × 17.8 m = 9.64 cm     ← 差 3%
（θ/2 来自点在窗内近似均匀分布，平均 |Δt| ≈ W/2）
```

再补两个点检查：最大位移 90.64 cm 落在 **84.5 m 远**的点（θ/2×84.5≈0.9 m）✓；
静止数据最大 17.80 cm（远点，最大 range 99.6 m，0.136°→0.0024 rad×75 m 量级）✓。
逐窗"旋转-位移"相关系数 r=0.75（剩余方差来自各窗距离分布不同）。

### 6.5 `--trans` 贡献的量化（诚实的负结果）

同一输入分别跑纯旋转与 `--trans`，逐点求差：

```
平移项的实际贡献：均值 0.18 mm，最大 1.18 mm
```

即本数据 0.1 s 窗内平移畸变本身就在毫米级（0.5 m/s²×0.1²/2≈2.5 mm 上限），
**旋转才是主项**。不是 bug，是物理——换更长窗（比如 1 s）或更晃的数据它才会显出来。

## 8. 假设与限制（什么情况下这套结果不可信）

1. **外参 = 单位阵**：假设 IMU 与雷达同壳体、轴对齐（同设备同抓包是佐证，但没标定）。
   若实际有安装角，补偿方向就是错的——需要外参标定后先旋转点或旋转 ω。
2. **匀速/匀加速平移补不了**：v₀=0 + 窗均值重力（无速度观测的本质限制），
   `--trans` 只补振荡项；本数据上贡献 0.18 mm。
3. **陀螺偏置直接进积分**：99999 那种 0.018 rad/s 若主要是偏置，
   每窗会"补偿"出 0.1° 的假旋转（静止数据位移 1.2 cm 主要来自它）。
   确有需要用 `--gyro-bias wx,wy,wz` 扣除（静止段均值估计）。完整的偏置在线估计
   需要外部观测（预积分理论里是和状态一起优化的）。
4. **w18（设备 B）没有 IMU 流**，做不了去畸变。
5. **只到"参考时刻的传感器系"**：要与 WaterScenes 世界系对齐还需要 yaw（无磁力计）
   与外参——那是下一步的事。
6. IMU 断流超过 0.5 s 的窗不补偿（原样透传、保留原时间戳，可从 `uncovered` 数查）。
